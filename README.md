## 📚 Програма воркаута (5 частин, 202 завдання)

1. **Частина 1: Синтаксис функцій, параметри та повернення значень (40 завдань)**  
   `src/01-syntax-params-return.js`  
   - Function Declaration vs Function Expression vs Arrow Functions `() => {}`.
   - Параметри за замовчуванням (Default Parameters).
   - Залишкові параметри (Rest Parameters `...args`).
   - Патерн Early Return (ранній вихід) для уникнення глибокої вкладеності `if/else`.
   - Валідація аргументів: перевірка типів, числових діапазонів та рядків.

2. **Частина 2: Області видимості, Hoisting та Замикання (Closures) (40 завдань)**  
   `src/02-scope-hoisting-closures.js`  
   - Global, Function та Block Scope (`var` vs `let` / `const`).
   - Hoisting (підняття змінних та функцій) і Temporal Dead Zone (TDZ).
   - Замикання (Closures): створення фабрик функцій, збереження внутрішнього стану.
   - Приватні змінні та інкапсуляція даних без класів.
   - Комбінація функцій з циклами та обробкою двовимірних матриць.

3. **Частина 3: Функції вищого порядку (HOF), Рекурсія та Патерни (42 завдання)**  
   `src/03-hof-pipelines-patterns.js`  
   - Функції як сутності першого класу (First-class Citizens) та функції зворотного виклику (Callbacks).
   - Власні поліфіли функціональних методів: `myMap`, `myFilter`, `myReduce`.
   - Композиція функцій: реалізація конвеєрів `pipe(...)` та `compose(...)`.
   - Каррінг (Currying) та часткове застосування (Partial Application).
   - Кешування обчислень через мемоізацію (Memoization).
   - Рекурсивні алгоритми: глибинний обхід вкладених структур, розрахунки факторіалів і дерев.
   - Патерн надійності: Circuit Breaker для нестабільних операцій.

4. **Частина 4: Винятки та обробка помилок (Error Handling) (40 завдань)**  
   `src/04-exceptions-error-handling.js`  
   - Конструкція `try...catch...finally`: перехоплення синхронних помилок.
   - Генерація власних винятків через інструкцію `throw new Error(...)`.
   - Створення кастомних ієрархій класів помилок (`ValidationError`, `AuthError`, `NotFoundError`).
   - Патерни Defensive Programming (захисне програмування).
   - Безпечний парсинг JSON без падіння додатку (`safeJsonParse`).
   - Повторні спроби виконання із затримкою (Retry Mechanism).

5. **Частина 5: Інтерактивні DOM Міні-проєкти (40 завдань)**  
   `src/05-dom-mini-projects.js`  
   - Пошук елементів у документі: `getElementById`, `querySelector`, `querySelectorAll`.
   - Маніпуляція вмістом та класами: `textContent`, `classList.toggle`, `classList.add`, `classList.remove`.
   - Прослуховування подій: `addEventListener('click')`, `addEventListener('input')`.
   - Міні-проєкти: клікери, перемикачі теми (Dark / Light Mode), модальні діалогові вікна, спливаючі повідомлення (Toast Notifications), акордеони, валідатори паролів у реальному часі, інтерактивні зіркові рейтинги (Star Rating), динамічні фільтри списків та Drag & Drop.
