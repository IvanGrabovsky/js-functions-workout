# ⚡ JS Functions Mastery Workout (Модуль 7: Функції)

Практичний воркаут з роботи з функціями в JavaScript в естетиці **Supabase Dark UI**:
- **Частина 1:** Синтаксис функцій, параметри за замовчуванням, Rest ...args, Early Return, валідація рядків і чисел (30 завдань).
- **Частина 2:** Області видимості, Hoisting, замикання (Closures), приватний стан, структури даних та обробка 2D-матриць із циклами (30 завдань).
- **Частина 3:** Функції вищого порядку (HOF), поліфіли map/filter/reduce, пайплайни pipe/compose, каррінг, мемоізація, рекурсія та Circuit Breaker (32 завдання).

## Запуск проекту локально
```bash
npm install
npm run dev
```
