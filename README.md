# ⚡ JS Functions, Exceptions & DOM Mastery Workout

Практичний воркаут з роботи з функціями, винятками та інтерактивними DOM-компонентами в JavaScript в естетиці **Supabase Dark UI**:
- **Частина 1:** Синтаксис функцій, параметри за замовчуванням, Rest ...args, Early Return, валідація рядків і чисел (40 завдань).
- **Частина 2:** Області видимості, Hoisting, замикання (Closures), приватний стан, структури даних та обробка 2D-матриць із циклами (40 завдань).
- **Частина 3:** Функції вищого порядку (HOF), поліфіли map/filter/reduce, пайплайни pipe/compose, каррінг, мемоізація, рекурсія та Circuit Breaker (42 завдання).
- **Частина 4:** Винятки та обробка помилок (try...catch...finally, throw, кастомні класи помилок, defensive programming) (40 завдань).
- **Частина 5:** DOM Міні-проекти (Інтерактивні кнопки, перемикачі теми, модалки, тости, акордеони, валідація форм, star rating, drag & drop) (40 завдань).

Всього: **202 комплексних завдання**, що забезпечують 100% готовність до комерційної frontend-розробки.
